## 工具

- **VS Code** — 写字的地方。装了两个插件：一个中文标点高亮，一个把全角空格画出来。
- **ffmpeg** — 把四百兆的星云裁成一点五兆的循环。命令行不好记，但快、稳、免费。
- **Chrome 的开发者工具** — 调色、量间距、看性能。这一站的一半设计是在它的设备模拟器里改出来的。
- **Git 与 GitHub Pages** — 版本与托管。推送即发布，没有别的魔法。

## 字体

站上不引外部字体，尽量用系统自带的宋体与楷体，因为中文网页字体动辄几兆：

- **思源宋体 / Noto Serif SC** — 有则用之，笔画最舒服；
- **宋体 / SimSun** — Windows 的常备；
- **楷体 / KaiTi** — 用在印章、小字与引文处。

```note 笺注
若你希望跨平台完全一致，可以把 Noto Serif SC 的子集放进 assets/fonts/。代价是首屏多下载几百 KB，这一站暂时不做这个取舍。
```

## 素材

- **星云影像** — 来自 Wallpaper Engine 创意工坊的一段四 K 循环，已裁切压制成二十秒的网页背景。
- **远山** — 手写的 SVG 路径，三层，用群青到靛蓝的透明度叠出景深。
- **纸纹** — 一段 `feTurbulence` 生成的噪点，几乎看不见，但拿掉之后整页会显得「塑料」。
- **印章** — 一个圆角方块、两个字、一次两度的旋转。没有用图片。

## 书与文

- 《中国传统色：故宫里的色彩美学》——这张蓝色系色卡的最初来源。
- 《CSS 世界》——关于盒模型与布局，中文写得最耐心的一本。
- 《The Elements of Typographic Style》——行距、字号、留白，都能在这里找到理由。
