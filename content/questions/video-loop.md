## 原始素材

原片是一段四 K、五分钟、近 400 MB 的星云动画。它适合当桌面壁纸，不适合当网页背景。

网页背景需要的不是「完整」，而是「够用」：

- 屏幕上看不出差别；
- 循环起来不突兀；
- 首屏不要拖慢。

## 处理

只截取其中二十秒，缩到 1600 × 900，二十四帧，去掉音轨：

```bash
ffmpeg -ss 40 -t 20 -i source.mp4 \
  -vf "fps=24,scale=1600:900:flags=lanczos" \
  -c:v libx264 -preset slow -crf 30 \
  -movflags +faststart -an galaxy.mp4
```

结果 **1.5 MB**。若用原来那份，是它的两百多倍。

另外压了一版 960 × 540（约 350 KB），窄屏的机器只取这一版——用 JavaScript 按视口宽度选源，比让手机去下高清版聪明。

## 省电的三道闸

视频背景最怕「用户看不见，它却在烧电」。三道闸：

```js
// 一、切回古风就暂停
if (theme !== 'cosmos') video.pause();

// 二、标签页切走就暂停
document.addEventListener('visibilitychange', () => {
  document.hidden ? video.pause() : video.play();
});

// 三、系统要求减少动态效果，就不要自动播放
if (media('(prefers-reduced-motion: reduce)').matches) return;
```

`preload="none"` 也是关键：不切到星穹，这段视频根本不会被下载。

## 实测

在中端笔记本上用浏览器性能面板跑了一遍，星穹主题、滚动阅读时：

| 项目 | 数值 |
| --- | --- |
| 视频解码 | 约占一个核心的 6% – 10% |
| 星子画布 | 约 3% |
| 首屏传输（桌面） | 1.5 MB + 页面本体约 120 KB |
| 首屏传输（手机） | 350 KB + 页面本体约 120 KB |

代价可以接受。合上盖子、切走标签页之后，两者都归零。

```note 笺注
如果你用的是集成显卡的老机器，视频会把风扇吹起来。这种情况下，换回古风就对了——它本来就是为了让人有得选。
```

## 一个遗憾

二十秒的片段首尾并不天然衔接，循环处会有一跳。

试过正放接倒放的做法，需要一个本站构建环境里没有的滤镜；也试过两段视频交叉淡入淡出，代价是要同时解码两份。最后选择让光幕和星子去分散注意力——**比起完美的循环，我更在意它不卡。**
