## 一个骨架，两副面孔

站里的每一个元素都只写一次：卡片、条目、正文、页脚。它们的颜色、阴影、字体全部来自 CSS 变量，切换主题只是把 `data-theme` 从 `guofeng` 换成 `cosmos`。

这副骨架必须同时成立，所以每个部件都要满足两个条件：

1. 尺寸、间距在两个主题下完全一致；
2. 所有「感觉」都只由变量决定——色、光、材质，不碰布局。

## 变量对照

两套皮肤的关键差别并不多，大约十来个变量：

| 变量 | 古风 | 星穹 |
| --- | --- | --- |
| `--paper` | `#EDF5F6` 月白 | `#04070F` 深空 |
| `--ink` | `#12313F` 墨蓝 | `#E9F4FF` 星白 |
| `--accent` | `#065279` 靛蓝 | `#30DFF3` 湖蓝 |
| `--card` | 半透明白纸 | 磨砂玻璃 |
| `--title-shadow` | 纸上的浮影 | 青色辉光 |

换过去之后，连标题的呈现方式都变了：古风是一枚压得住纸的黑字，星穹则用渐变把字浸在光里。

## 星穹的三层

星穹不是简单地换一张深色背景，它是三层叠起来的：

- **影像层**：一段二十秒的星云循环，压暗、降饱和，缓慢推近；
- **光幕层**：径向渐变收暗四角，让正文始终压得住；
- **星子层**：画布上的两百来颗星，各自呼吸，偶有流星斜过。

三层都设了 `pointer-events: none`，并且只在星穹主题下才运行——回古风时视频暂停、画布停笔，不白白耗电。

```note 笺注
若系统设置了「减少动态效果」，影像不自动播放、星子只画一帧静的，页面依然成立。动效是锦上添花，不是必要条件。
```

## 过渡

换肤那一下也有讲究。只加一个类名，让整页的颜色在 0.7 秒里同时呼吸，再叠一层从按钮位置扩散的青色光晕——像一滴墨落进水里。

```css
html.is-switching body,
html.is-switching .section-card,
html.is-switching .site-head {
  transition: background .7s ease, color .45s ease,
              border-color .7s ease, box-shadow .7s ease;
}
```

过渡结束后这个类就被摘掉，免得页面上的悬停反馈也变得黏糊糊。
