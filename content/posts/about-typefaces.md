## 先说不做的事

不下载字体。

中文网页字体最小也要几百 KB，完整字重动辄几兆。对一个人的博客来说，为了「好看一点」让每个访客多下三兆，不划算。

所以我只用系统字体，把已有的用对。

## 两套字

**深空**用无衬线：Inter、系统 UI、苹方、微软雅黑。干净，适合小字号与代码。

**山水**用衬线：宋体、思源宋体。宋体在屏幕上看起来「薄」，但它有笔锋，和那张壁纸是一路的。

```css
html[data-theme="guofeng"] {
  --font-display: "Songti SC", "STSong", "Noto Serif SC", "SimSun", serif;
}
html[data-theme="cosmos"] {
  --font-display: "Inter", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
}
```

## 三处细节

### 字距

中文标题加了字距（`.1em` 到 `.14em`），但正文不加。标题是「看」的，正文是「读」的。

### 字重

宋体没有中间字重，`font-weight: 500` 会被渲染成常规或加粗。所以山水主题里标题统一用 500，宁可细一点，也不要糊成一块黑。

### 行高

正文的行高给到 1.9 至 2.05。中文的方块字比拉丁字母占地方，行距不够就会挤成一团。

> 排版没有玄学：字号、行高、字距，三个数调对了，页面就安静下来了。

## 最后的选择

山水主题的正文 17.5px、行高 2.05；深空主题 17px、行高 1.95。差得不多，但读起来是两种节奏。
