## 先选图，再选色

我不太相信「先定一个主色，再搭配」。对个人站点来说，更自然的顺序是：先找到一张让你停下来看的图，再从里面取色。

山水主题的图是一张樱花与楼台的照片。它自己已经是一套完整的配色了，我要做的只是把它的角色拆出来。

## 五个角色

| 角色 | 取自 | 用在哪 |
| --- | --- | --- |
| 纸 | 雾与浅色天空 | 页面底色 |
| 墨 | 屋檐、树干 | 正文与标题 |
| 樱 | 花瓣 | 悬停、点缀 |
| 水 | 河面的青灰 | 次要信息 |
| 灯 | 灯笼的红 | 强调、按钮 |

五个角色，不增不减。多一个颜色，页面就多一分噪音。

## 取色不是吸管的事

直接吸色往往不够用：照片里的颜色受光影影响，直接拿来当底色会脏。

我的做法是把它往纸的方向提亮、降饱和：

```css
--bg: #F4ECE6;      /* 雾色的提亮版 */
--text: #2A2420;    /* 墨色的暖调 */
--accent: #B4462F;  /* 灯笼红，降一点饱和 */
```

## 一条经验

> 照片只用来定调，不要直接拿来铺满。

真正让页面成立的是「纸」这个底色——它把照片里的热闹都接住了。
