## 写字

**VS Code**。没装太多插件，只留了两个：中文标点高亮，和把全角空格画出来。后者听起来无聊，但它让中文排版里的「空」变得可见。

## 压素材

**ffmpeg**。命令行不好记，但快、稳、免费。压一段四 K 视频成网页背景，一行命令的事。

```bash
ffmpeg -i in.mp4 -vf scale=1600:-2 -crf 30 -an out.mp4
```

## 量间距

浏览器开发者工具。这个站的一半设计是在它的设备模拟器里改出来的：拖到 1440、拖到 390，看哪里挤了、哪里散了。

## 看性能

还是开发者工具，Performance 面板。滚动时的掉帧、换肤时的一次重排，都能在这里看到。

## 版本与托管

**Git + GitHub Pages**。推送即发布，没有别的魔法。
