## 原始素材

原片是 4K、五分钟、接近 400 MB 的星云循环。它适合当桌面壁纸，不适合当网页背景。

网页背景需要的不是「完整」，而是三件事：屏幕上看不出差别、循环起来不突兀、首屏不要拖慢。

## 只做四件事

```bash
ffmpeg -ss 40 -t 20 -i source.mp4 \
  -vf "fps=24,scale=1600:900:flags=lanczos" \
  -c:v libx264 -preset slow -crf 30 \
  -movflags +faststart -an galaxy.mp4
```

1. 从第 40 秒开始，只取 20 秒；
2. 缩到 1600×900；
3. 帧率降到 24；
4. 去掉音轨，并把索引放到文件头（`faststart`）。

结果 **1.5 MB**，是原片的约两百分之一。

## 手机另给一份

窄屏没必要下载 1600 宽。另压一版 960×540，约 350 KB，按视口宽度选源：

```js
const src = matchMedia('(max-width: 760px)').matches
  ? 'assets/media/galaxy-960.mp4'
  : 'assets/media/galaxy.mp4';
```

## 不白耗电

视频背景最怕「看不见，却在烧电」。三道闸：

- 切到山水，立刻 `pause()`；
- 标签页切走，`visibilitychange` 里暂停；
- 系统开了「减少动态效果」，就不自动播放，只留一帧海报。

还有 `preload="none"`：不进深空主题，这段视频根本不会被下载。

## 一个遗憾

二十秒的首尾并不天然衔接，循环处会跳一下。

试过正放接倒放，需要构建环境里没有的滤镜；也试过两段交叉淡入，代价是要同时解码两份。最后让光幕和星子去分散注意力——**比起完美的循环，我更在意它不卡。**
