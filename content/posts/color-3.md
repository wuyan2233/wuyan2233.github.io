## 动效只做一件事

让变化看起来是连续的。

不是让页面「更高级」，也不是为了炫技。如果一段动画不能帮助人理解「刚刚发生了什么」，它就应该被删掉。

## 三处保留的动效

**换肤**：从按钮位置扩散一圈光晕，0.9 秒。它告诉用户「变的是整个世界，不只是颜色」。

**星子**：缓慢的明暗呼吸，偶尔一颗流星。它的作用是让静态的深空不显得死。

**落樱**：从顶部飘下的花瓣，速度很慢，数量很少。它存在的理由只有一个——那张壁纸本来就是会动的。

## 关掉的那些

- 卡片悬停的缩放（太吵）
- 数字滚动动画（没有意义）
- 页面进入时的全屏转场（每次都要等）

## 必须尊重系统设置

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .001ms !important;
    transition-duration: .001ms !important;
  }
}
```

以及脚本里的判断：开了「减少动态效果」，就不播放背景视频，星子和落樱只画一帧静的。页面依然成立。

## 一句判断标准

> 把动画全删掉，页面还能用吗？能，那动画就是装饰；不能，那它才是信息。

装饰可以有，但要少。
