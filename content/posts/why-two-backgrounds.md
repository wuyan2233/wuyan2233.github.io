## 起因

一开始只想做一套。深色背景、细线、玻璃卡片，看起来利落。但写了两周之后发现一个问题：**这样的一页，和「我」没什么关系。**

深空很漂亮，可它属于所有人。任何人都可以拿一段星云视频做背景，配上灰色文字，看起来都差不多。

所以我加了第二套。

## 两套是什么

- **深空**：星云循环影像、无衬线字、细网格、青紫辉光。适合晚上看，也适合代码。
- **山水**：一张樱与楼台的壁纸、宋体、暖纸色、灯笼红。适合白天，也适合读长文。

切换按钮在左上角，点一下就好，选择会被记住。

## 为什么不做成「一套自适应」

「自适应」的意思往往是：同一套东西，换个颜色。这样做最省事，也最没有性格——你得到的仍然是同一页，只是背景暗了一点。

我想要的更多一点：**换过去之后，字体、圆角、间距、强调色、甚至标题的写法都变了。** 同一个按钮在深空里是发光的胶囊，在山水里是一块深墨色的方块。

## 代价

代价是组件要写两遍样式。比如同样一个 `.entry` 卡片：

```css
/* 深空 */
html[data-theme="cosmos"] .entry {
  background: rgba(14, 20, 38, .52);
  border-radius: 16px;
  backdrop-filter: blur(12px);
}

/* 山水 */
html[data-theme="guofeng"] .entry {
  background: rgba(255, 252, 248, .74);
  border-radius: 5px;
  box-shadow: 0 1px 0 rgba(255,255,255,.6) inset;
}
```

不优雅，但很清楚。而且因为都挂在 `html[data-theme]` 下面，两套样式永远互不干扰。

> 一套结构和两副面孔之间，差的不是技术，是愿不愿意多写一遍。

## 一点私心

山水那一套用的是我收藏很久的一张壁纸：春天的楼台，樱花落在水面上。每次打开都像回到某个下午。

深空那一套没有故事，只有安静。两个都需要。
